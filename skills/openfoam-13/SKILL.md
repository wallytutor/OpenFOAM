# Using OpenFOAM 13

---

## When to use this skill

- Use this when writing or modifying OpenFOAM 13 cases.

- Do not use this skill for other OpenFOAM versions or programming languages.

---

## How to use this skill

- Prioritize searching solutions in the documentation.

Use the WebBrowser tool to navigate to the [OpenFOAM Forum](https://www.cfd-online.com/Forums/openfoam/) and use its search bar to look up the exact error code.

- When searching the forum, make sure to filter results belonging to versions prior to OpenFOAM 10 (as previous versions are significantly different) and avoid using any information from other OpenFOAM variants (e.g. `Esi`, `BlueCFD`, etc.).

---

## Documentation sources

- The primary source of information for OpenFOAM 13 documentation is to use the WebBrowser tool to navigate to the [OpenFOAM 13 documentation](https://cpp.openfoam.org/v13/index.html) and its [repository](https://github.com/OpenFOAM/OpenFOAM-13) (where you also find the [tutorials](https://github.com/OpenFOAM/OpenFOAM-13/tree/master/tutorials) with sample cases).

- Secondary sources of information are, in this order, use WebBrowser to navigate:
    - [User Guide](https://doc.cfd.direct/openfoam/user-guide-v13/contents)
    - [Documentation index](https://cfd.direct/openfoam/documentation/)
    - [openfoam.org](https://openfoam.org/)

- Do not use any information from [openfoam.com](https://www.openfoam.com/) and related sub-domains.
